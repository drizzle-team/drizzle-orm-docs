# Meet Drizzle Studio
🖥 Drizzle Studio is a modern web based database browser. Browse and edit your data, explore your schema
and run SQL — with zero setup on top of your existing database.

![Drizzle Studio](@/assets/images/drizzle-studio-overview.webp)

Studio connects to your database, introspects it and lets you browse, add, delete and update everything
based on your existing SQL schema.

## Drizzle Studio family
Studio comes in four flavours, all powered by the same database browser:

| Product | What it is | Pricing |
| :------ | :--------- | :------ |
| **[Studio for local development](#drizzle-studio-for-local-development)** | `drizzle-kit studio` in your Drizzle project                                            | free        |
| **[Drizzle Gateway](#drizzle-gateway)**                             | self-hosted Studio for your infrastructure, deployed as a Docker container or a binary     | free        |
| **[Chrome extension](#drizzle-studio-chrome-extension)**            | browse serverless databases right in their vendor consoles                                 | free        |
| **[Studio Component](#drizzle-studio-component)**                   | embeddable Studio for your own product                                                     | B2B offering |

## What you can do
- **Browse data** with pagination, filtering, multi-column sorting and column reordering
- **Edit data** inline — add, update and delete rows, in-place editable `json`, `boolean` and `enum` editors
- **Copy & paste** cell ranges, copy rows to clipboard or export them as `csv`/`sql`
- **Import** `csv` and `sql` files
- **Run SQL** in the SQL console with autocompletion, `explain`/`analyze` support and query telemetry
- **Run Drizzle queries** with the Drizzle runner
- **Explore your schema** — tables, views, columns, indexes, foreign keys, policies and privileges

## Drizzle Studio for local development
Drizzle Studio for local development is free forever and grabs everything it needs from your
[drizzle.config.ts](/docs/drizzle-config-file) file. It supports `PostgreSQL`, `MySQL`, `SQLite`, `SingleStore`,
`MSSQL` and `CockroachDB`.

<Steps>

#### Install dependencies
Make sure to go through our [get started](/docs/get-started) guides first!

<Npm>
  drizzle-orm@rc
  -D drizzle-kit@rc
</Npm>

#### Prepare your database schema
Check out extended schema declaration **[docs.](/docs/sql-schema-declaration)**
```typescript copy filename="schema.ts"
import { pgTable, serial, text, varchar } from "drizzle-orm/pg-core";

export const users = pgTable('users', {
  id: serial('id').primaryKey(),
  fullName: text('full_name'),
  phone: varchar('phone', { length: 256 }),
});
```

#### Prepare config file
Check out extended config file **[docs.](/docs/drizzle-config-file)**
```typescript copy filename="drizzle.config.ts"
import { defineConfig } from "drizzle-kit";
 
export default defineConfig({
  schema: "./schema/*",
  out: "./drizzle",
  dialect: 'postgresql',
  dbCredentials: {
    url: process.env.DB_URL,
  }
});
```
#### Launch Drizzle Studio
<Npx>
drizzle-kit studio
</Npx>

You can launch studio with `port` cli flag to customize process port and `verbose` flag for extended SQL statements logging
<Npx>
drizzle-kit studio --port 3000 --verbose
</Npx>

By default, Drizzle Studio will be launched on the `https://local.drizzle.studio` host, and studio server will be launched on 127.0.0.1 host but you can specify any host you want
<Npx>
drizzle-kit studio --host 0.0.0.0
</Npx>
</Steps>

<Callout type="info" title="Safari and Brave">
Safari and Brave block access to localhost by default. You need to install [mkcert](https://github.com/FiloSottile/mkcert)
and generate a self-signed certificate — check out the [drizzle-kit studio](/docs/drizzle-kit-studio) docs.
</Callout>

The hosted version of Studio is meant for local development and is **not** meant to be exposed on a remote machine —
for that we have [Drizzle Gateway](#drizzle-gateway).

## Drizzle Gateway
[Drizzle Gateway](https://gateway.drizzle.team) is a free self-hosted Drizzle Studio on steroids.
It's a single Docker image (or a standalone binary) that you put into your own infrastructure, connect privately
to your databases and share with your team.

![Drizzle Gateway](@/assets/images/drizzle-gateway.webp)

Unlike `drizzle-kit studio`, Gateway doesn't need a Drizzle project — you add database connections right in the UI,
keep them in a persistent volume and protect access with a master password and per-user passcodes.

<CodeTabs items={["Docker", "Railway"]}>
```shell
# pull latest version
docker pull ghcr.io/drizzle-team/gateway:latest

# persistent volume is required for the configuration file
docker volume create drizzle-gateway

# start the gateway
docker run -d \
  --name drizzle-gateway \
  --restart always \
  -p 4983:4983 \
  -e PORT=4983 \
  -e STORE_PATH=./app \
  -e MASTERPASS=your_master_password \
  -v drizzle-gateway:/app \
  ghcr.io/drizzle-team/gateway:latest
```
```shell
# one click deploy via Railway template
https://railway.com/new/template/drizzle-studio-gateway
```
</CodeTabs>

Once it's running, Gateway is available at `http://localhost:4983`. It works on both `arm` and `amd` architectures,
and standalone binaries are available for macOS and Linux — see [gateway.drizzle.team](https://gateway.drizzle.team)
for installation options and the changelog.

## Drizzle Studio Chrome extension
Drizzle Studio [chrome extension](https://driz.link/extension) lets you browse
[PlanetScale](https://planetscale.com), [Cloudflare D1](https://developers.cloudflare.com/d1/),
[Vercel Postgres](https://vercel.com/docs/storage/vercel-postgres) serverless databases
directly in their vendor admin panels — no local setup, no connection strings.

We also have [sqlite.drizzle.studio](https://sqlite.drizzle.studio) to browse SQLite files right in your browser.

## Drizzle Studio Component
While Studio for local development is free forever and meant to just enrich the Drizzle ecosystem,
we have a **B2B offering** of an embeddable version of Drizzle Studio for businesses.

**Drizzle Studio Component** is a pre-bundled framework agnostic web component of Drizzle Studio
which you can embed into your UI — `React` `Vue` `Svelte` `VanillaJS` etc.

That is an extremely powerful UI element that can elevate your offering if you provide Database as a SaaS
or data centric SaaS solutions based on SQL, or for private non-customer facing in-house usage.

It's highly customisable: we have an advanced [theming platform](https://drizzle.studio), an opt-in SQL query runner
and we can add various partner-specific customizations on demand 👍

## FAQ
#### Is Drizzle Studio open source?
No. Drizzle ORM and Drizzle Kit are fully open sourced, while Studio is not.

Drizzle Studio for local development is free to use forever to enrich the Drizzle ecosystem,
open sourcing one would've break our ability to provide B2B offerings and monetise it, unfortunately.

#### Can I deploy Studio to my VPS?
Yes — that's exactly what [Drizzle Gateway](#drizzle-gateway) is for. The hosted `local.drizzle.studio`
version is meant for local development only.

#### Does Studio send my data anywhere?
No. Both `drizzle-kit studio` and Gateway run the database connection on your machine or in your infrastructure,
your data never leaves it.
