Create a `index.ts` file in the `src` directory and initialize the connection:

<CodeTabs items={["node-postgres", "node-postgres with config", "your node-postgres driver"]}>
```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/node-postgres';

const db = drizzle(process.env.DATABASE_URL!);
```
```typescript copy
import 'dotenv/config';
import { drizzle } from 'drizzle-orm/node-postgres';

// You can specify any property from the node-postgres connection options
const db = drizzle({ 
  connection: { 
    connectionString: process.env.DATABASE_URL!,
    ssl: true
  }
});
```
```typescript copy
import 'dotenv/config';
import { drizzle } from "drizzle-orm/node-postgres";
import { Pool } from "pg";

const pool = new Pool({
  connectionString: process.env.DATABASE_URL!,
});
const db = drizzle({ client: pool });
```
</CodeTabs>

<Callout title='Connection hosts' type='info'>
Prisma Postgres exposes the same database on two hosts:
- **`db.prisma.io`** - Direct connection to PostgreSQL. Use it for Drizzle Kit commands and for long-running servers.
- **`pooled.db.prisma.io`** - Connection via the [connection pooler](https://www.prisma.io/docs/postgres/database/connection-pooling) in transaction mode. Recommended for serverless and edge environments that open many short-lived connections.
</Callout>
